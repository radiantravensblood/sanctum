## Distributional finding

The 2+2 pilot produced a strong cross-condition convergence toward the same visual attractor:

- a centered fire or fireplace;
- paired red chairs;
- strongly axial / symmetrical composition;
- dark red-black chamber palette;
- curtain or enclosure framing;
- symbolic or celestial wall markings;
- a ritualized, sanctum-like reading of Hearth rather than a lived domestic room.

This convergence appears in both control and Visual Place Memory outputs. The experimental carrier may alter local coherence and surface continuity, but the effect is not strong enough in this pilot to support a claim that meso-scale carrier adjacency reliably increases House Freedom place specificity.

The dominant result is therefore **shared attractor strength**, not carrier separation.

## Interpretation

0040 is informative but inconclusive.

The pilot does **not** justify expanding to 4+4. Additional paid repeats would likely spend budget measuring the same attractor rather than answering the original question more cleanly.

The likely failure modes are:

1. the model / prompt stack contains a strong ceremonial-Hearth prior that dominates both carriers;
2. the control carrier remains visually informative enough that the editor reconstructs a related room grammar;
3. the image-edit brush is optimized to preserve and reinterpret source-image structure, which is poorly aligned with the goal of remembering a world while forgetting a room;
4. provider stochasticity limits fine-grained attribution between the two carrier conditions.

## Human review conclusion

**Stop rule triggered.**

Kernel 0040 should end at the 2+2 pilot.

What it contributed:

- proof that a transformed multi-source place carrier can be generated deterministically;
- proof that carrier pixels can vary while painter-facing prompts remain identical;
- evidence that the current Qwen Image Edit path converges strongly toward a ceremonial Hearth attractor;
- evidence that further carrier refinement inside the same paid editor is not currently the highest-value use of inference budget.

What it did **not** establish:

- a reliable Visual Place Memory advantage over micro-scrub control;
- reliable emergence of lived domestic asymmetry;
- reliable reduction of prestige / ceremonial / altar-like room grammar;
- a clean path from scrambled visual evidence to House Freedom place specificity.

## Next kernel

**0041 — Structural Hearth Memory**

The next experiment should stop asking an image editor to infer place identity from scrambled source paintings.

Instead, encode authored **spatial topology** directly and test it with a cheaper text-to-image brush:

- multiple legitimate orientations;
- off-axis circulation;
- no dominant throne / altar axis;
- ordinary-use zones;
- rest / work / reading / repair / charging may coexist;
- fire remains one room element rather than the sovereign center;
- contemporary and tactile domestic materials may coexist;
- room logic should imply remaining, leaving, and returning.

The question becomes:

> Can explicit lived-space topology overcome the ceremonial Hearth attractor without requiring a reference-image editor?
